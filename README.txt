BrightDay Version 7 — Tablet + Big-Screen Edition

NO PAID API OR SUBSCRIPTION. No Node.js needed to view the HTML locally.

UPGRADE & BACKUP
1. In V6 Parent Mode choose Save backup; keep its JSON file safe.
2. Scan this ZIP with Windows Security, extract, and open index.html in Chrome or Edge.
3. Check tasks, stars, and parent PIN. A different folder, origin or browser can have separate local storage.
4. If tasks are missing, enter Parent Mode and choose Restore backup.
5. The PIN is stored separately from the JSON backup. If you move to a new device, create a new PIN.

TABLET & TV
- Tablet view: large touch controls, daily or weekly calendar.
- Big-screen view: click TV Big-screen view; switches to a 7-day dashboard with larger buttons.
- Full screen: press the Full screen button if browser supports it.
- Android TV remote: use D-pad arrows, OK/Enter; mouse/air mouse may work better depending on device.
- Each Android device/browser saves its own tasks; there is NO automatic syncing.

INSTALL ON ANDROID
A file opened from Downloads is NOT generally an installable Android app.
To enable Add to Home screen/Install: host the entire folder on a trusted HTTPS static host (e.g. GitHub Pages), preserving all files and folders. Open the resulting HTTPS URL in Chrome on Android tablet and choose Install app/Add to Home screen from browser menu. Android TV browsers vary; you may need a compatible TV browser or mouse/air mouse, and PWA install is not guaranteed.
For offline usage the web app must load from HTTPS at least once and the service worker must successfully cache it. Test offline before depending on it.
IMPORTANT: Local storage is associated with website origin. Back up on Windows, host the app, then restore the JSON backup on the tablet (Parent Mode). There is no automatic transfer from Windows or between tablet and TV box. Do not publish backups or your PIN.

PRIVACY / SAFETY
Data is stored in local browser storage on each device. The parent PIN is only a convenience barrier (not secure against technically skilled users). No images are sent to paid AI services. Do not share the JSON backup publicly.

LIMITATIONS
This is a PWA web app, not an Android APK. Hosting and testing on real Android TV hardware remain to be done. Voice playback depends on available system voices. Some TV box browsers may not support speech or installable PWAs.
